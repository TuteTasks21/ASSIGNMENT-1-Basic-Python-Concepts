# ASSIGNMENT-1-Basic-Python-Concepts

Task-1
This Python program is a simple calculator that performs basic mathematical operations: addition, subtraction, multiplication, and division. The program takes two numbers as input from the user and displays the results of each operation.

Example Output
When you run the program, it will prompt you to enter two numbers. Here’s an example of what the output might look like:
Enter the first number: 10
Enter the second number: 5

Results:
Addition: 10 + 5 = 15
Subtraction: 10 - 5 = 5
Multiplication: 10 * 5 = 50
Division: 10 / 5 = 2.0



Task-2
This Python program creates a personalized greeting for the user. It takes the user's first name and last name as input, concatenates them to form a full name, and then prints a customized greeting message.

Example Output
When you run the program, it will prompt you to enter your first and last names. Here’s an example of what the output might look like:
Enter your first name: John
Enter your last name: Doe

Results:
Hello, John Doe! Welcome to our program!
